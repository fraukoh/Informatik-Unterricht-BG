Aufgabe 1:

Gegeben ist das Array punkte = [12, 45, 7, 33, 28].
Durchlaufe das Array von vorne nach hinten und gib jedes Element aus.
Erwartete Ausgabe

12
45
7
33
28
▼ Lösung anzeigen
punkte = [12, 45, 7, 33, 28]
for ind in range(0,len(punkte)):
    print(punkte[ind])

Aufgabe 5:

Gegeben ist das Array werte = [14, 9, 27, 5, 18].
Finde die größte Zahl im Array, indem du das Array einmal von vorne nach hinten durchläufst.
Erwartete Ausgabe

Größte Zahl: 27
▼ Lösung anzeigen
werte = [14, 9, 27, 5, 18]
groesste = werte[0]
for ind in range(0,len(werte)):
    if werte[ind] > groesste:
        groesste = werte[ind]
print("Größte Zahl:", groesste)

Aufgabe 6:

Gegeben ist das Array werte = [14, 9, 27, 5, 18].
Finde den Index der kleinsten Zahl im gesamten Array.
Erwartete Ausgabe

Index der kleinsten Zahl: 3
▼ Lösung anzeigen
werte = [14, 9, 27, 5, 18]
min_index = 0
for ind in range(0,len(werte)):
    if werte[ind] < werte[min_index]:
        min_index = ind
print("Index der kleinsten Zahl:", min_index)

Aufgabe 7:

Gegeben ist das Array werte = [14, 9, 27, 70, 18].
Finde den Index der kleinsten Zahl nur im Teilbereich ab Index 2 (also in [27, 70, 18]).
Erwartete Ausgabe

Index der kleinsten Zahl ab Index 2: 4
▼ Lösung anzeigen
werte = [14, 9, 27, 70, 18]
start = 2
min_index = start
for ind in range(start, len(werte)):
    if werte[ind] < werte[min_index]:
        min_index = ind
print("Index der kleinsten Zahl ab Index 2:", min_index)

Aufgabe 8:

Gegeben ist das Array werte = [14, 9, 27, 5, 18].
Tausche die Elemente an den Indizes 0 und 3 und gib das Array danach aus.
Erwartete Ausgabe

[5, 9, 27, 14, 18]
▼ Lösung anzeigen
werte = [14, 9, 27, 5, 18]
hilf = werte[0]
werte[0] = werte[3]
werte[3] = hilf
print(werte)

Aufgabe 9:

Gegeben ist das Array zahlen = [4, 1, 7, 3, 9, 2].
Vergleiche jeweils zwei benachbarte Elemente. Wenn das linke Element größer ist als das rechte, gib das Paar aus.
Erwartete Ausgabe

4 > 1
7 > 3
9 > 2
▼ Lösung anzeigen
zahlen = [4, 1, 7, 3, 9, 2]
for ind in range(0,len(zahlen) - 1):
    if zahlen[ind] > zahlen[ind + 1]:
        print(zahlen[ind], ">", zahlen[ind + 1])

Aufgabe 10:

Gegeben ist das Array zahlen = [4, 1, 7, 3, 9, 2].
Gehe einmal von vorne nach hinten durch das Array. Tausche jeweils zwei benachbarte Elemente, wenn das linke größer ist als das rechte. Gib das Array danach aus.
Erwartete Ausgabe

[1, 4, 3, 7, 2, 9]
▼ Lösung anzeigen
zahlen = [4, 1, 7, 3, 9, 2]
for ind in range(0,len(zahlen) - 1):
    if zahlen[ind] > zahlen[ind + 1]:
        hilf = zahlen[ind]
        zahlen[ind] = zahlen[ind + 1]
        zahlen[ind + 1] = hilf
print(zahlen)
