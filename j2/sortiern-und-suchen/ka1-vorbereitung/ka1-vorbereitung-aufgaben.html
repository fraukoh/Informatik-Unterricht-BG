Teil 2: Sortieren

Aufgabe 11

Beim Handy-Quiz stehen die Punktzahlen in highscores = [42, 15, 67, 8, 53, 29]. Sortieren Sie das Array mit Bubble Sort aufsteigend und geben Sie es aus.

Erwartete Ausgabe

[8, 15, 29, 42, 53, 67]
▼ Lösung anzeigen
highscores = [42, 15, 67, 8, 53, 29]
laenge = len(highscores)
for i in range(1, laenge):
    for j in range(0, laenge - i):
        if highscores[j] > highscores[j + 1]:
            zwischenspeicher = highscores[j]
            highscores[j] = highscores[j + 1]
            highscores[j + 1] = zwischenspeicher
print(highscores)

Aufgabe 13

Die Rundenzeiten eines Rennspiels stehen in zeiten = [88, 21, 64, 17, 45, 30]. Sortieren Sie das Array mit Selection Sort aufsteigend und geben Sie es aus.

Erwartete Ausgabe

[17, 21, 30, 45, 64, 88]
▼ Lösung anzeigen
zeiten = [88, 21, 64, 17, 45, 30]
laenge = len(zeiten)
for akt_idx in range(laenge - 1):
    min_idx = akt_idx
    for j in range(akt_idx + 1, laenge):
        if zeiten[j] < zeiten[min_idx]:
            min_idx = j
    zwischenspeicher = zeiten[akt_idx]
    zeiten[akt_idx] = zeiten[min_idx]
    zeiten[min_idx] = zwischenspeicher
print(zeiten)
