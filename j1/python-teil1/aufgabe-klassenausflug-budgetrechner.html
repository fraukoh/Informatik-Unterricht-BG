Aufgabe: Klassenausflug – Budgetrechner 💶🚌

Ihr plant einen Klassenausflug und habt ein gemeinsames Budget in der Klassenkasse.
Schreiben Sie ein Programm, das berechnet:

  • wie hoch die Gesamtkosten für Bus, Eintritt und Essen sind,
  • wie viel Geld übrig bleibt,
  • wie viel Restgeld pro Person bleibt.

Verwenden Sie dafür Variablen z.B. für:

  • Startbudget der Klasse,
  • Buskosten (insgesamt),
  • Anzahl der Teilnehmer,
  • Eintritt pro Person,
  • Essen pro Person.

Nutzen Sie die Rechenoperatoren +, -, * und /.

#Hier den Programmcode eingeben und mit STRG+ENTER ausführen
# Beispielwerte:
startbudget = 750.0
buskosten = 320.0
teilnehmer = 24
eintritt_pro_person = 8.5
essen_pro_person = 6.0

# Berechnungen:
gesamt_eintritt = teilnehmer * eintritt_pro_person
gesamt_essen = teilnehmer * essen_pro_person
gesamtkosten = buskosten + gesamt_eintritt + gesamt_essen
restbudget = startbudget - gesamtkosten
rest_pro_person = restbudget / teilnehmer

# Ausgabe:
print("🚌 Klassenausflug – Budgetrechner")
print("Startbudget:", startbudget, "€")
print("Buskosten:", buskosten, "€")
print("Gesamter Eintritt:", gesamt_eintritt, "€")
print("Gesamte Essenskosten:", gesamt_essen, "€")
print("-------------------")
print("Gesamtkosten:", gesamtkosten, "€")
print("Restbudget:", restbudget, "€")
print("Rest pro Person:", rest_pro_person, "€")
