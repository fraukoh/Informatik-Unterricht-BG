Aufgabe 1:

Bubble Sort – Lottozahlen

Die Zahlen der aktuellen Lottoziehung liegen in der Reihenfolge der Ziehung in einem Array lotto vor [48, 5, 17, 32, 7, 29] und sollen noch sortiert werden. Sie erhalten den Auftrag, ein entsprechendes Programm zu entwickeln, das die Lottozahlen mit Hilfe des Sortieralgorithmus Bubble Sort sortiert und die sortierten Zahlen in der Konsole ausgibt.

Zeichnen Sie außerdem ein Struktogramm zu dem Programm.

Erwartete Ausgabe

[5, 7, 17, 29, 32, 48]
▼ Lösung anzeigen
lotto = [48, 5, 17, 32, 7, 29]
laenge = len(lotto)

# Sortieren
for i in range(1, laenge):
    for j in range(0, laenge - i):
        if lotto[j] > lotto[j + 1]:
            zwischenspeicher = lotto[j]
            lotto[j] = lotto[j + 1]
            lotto[j + 1] = zwischenspeicher

# Ausgabe
print(lotto)

isbn = [9783866801929, 9783957311320, 9783442267743, 9783423214599, 9783442314928]

for i in range(1, laenge):

Aufgabe 3:

Sortieren von Messwerten

In einem wissenschaftlichen Experiment wurden Messwerte erfasst und in einem Array messwerte gespeichert, z. B. [12.5, 7.8, 3.14, 9.7, 6.2]. Die Messwerte sollen nun für die weitere Analyse aufsteigend sortiert werden.

Entwickeln Sie ein Programm, welches die Messwerte mittels Bubblesort sortiert und sowohl die unsortierten als auch die sortierten Werte in der Konsole ausgibt.

Erwartete Ausgabe

Unsortiert: [12.5, 7.8, 3.14, 9.7, 6.2]
Sortiert: [3.14, 6.2, 7.8, 9.7, 12.5]
▼ Lösung anzeigen
messwerte = [12.5, 7.8, 3.14, 9.7, 6.2]
laenge = len(messwerte)

print("Unsortiert:", messwerte)

# Sortieren
for i in range(1, laenge):
    for j in range(0, laenge - i):
        if messwerte[j] > messwerte[j + 1]:
            zwischenspeicher = messwerte[j]
            messwerte[j] = messwerte[j + 1]
            messwerte[j + 1] = zwischenspeicher

# Ausgabe
print("Sortiert:", messwerte)

Aufgabe 4:

Zwischenstand untersuchen

Um Bubble Sort besser zu verstehen, sollt ihr den Algorithmus nicht bis zum Ende laufen lassen, sondern nach einer festgelegten Anzahl äußerer Durchläufe anhalten und den Zwischenstand betrachten.

Gegeben ist das Array zahlen = [9, 3, 7, 1, 5, 2]. Schreibt ein Programm, das genau drei äußere Durchläufe von Bubble Sort ausführt und danach den aktuellen Zustand des Arrays ausgibt.

Tipp: Die äußere Schleife läuft sonst bis laenge - 1. Begrenzt sie so, dass nur drei Durchläufe stattfinden.

Erwartete Ausgabe

Nach 3 Durchläufen: [1, 3, 2, 5, 7, 9]
▼ Lösung anzeigen
zahlen = [9, 3, 7, 1, 5, 2]
laenge = len(zahlen)
durchlaeufe = 3

for i in range(0, durchlaeufe):
    for j in range(0, laenge - i):
        if zahlen[j] > zahlen[j + 1]:
            zwischenspeicher = zahlen[j]
            zahlen[j] = zahlen[j + 1]
            zahlen[j + 1] = zwischenspeicher

print("Nach 3 Durchläufen:", zahlen)

Aufgabe 5:

Aufwand messen – Täusche zählen

Bei Sortieralgorithmen ist nicht nur das Ergebnis interessant, sondern auch der Aufwand. Ein einfaches Maß dafür ist die Anzahl der Täusche.

Gegeben ist das Array zahlen = [6, 2, 8, 1, 4]. Schreibt ein Programm, das die Zahlen mit Bubble Sort sortiert und dabei mitzählt, wie oft zwei benachbarte Elemente getauscht werden. Am Ende sollen das sortierte Array und die Anzahl der Täusche ausgegeben werden.

Erwartete Ausgabe

Sortiert: [1, 2, 4, 6, 8]
Anzahl Täusche: 6
▼ Lösung anzeigen
zahlen = [6, 2, 8, 1, 4]
laenge = len(zahlen)
tausche = 0

for i in range(1, laenge):
    for j in range(0, laenge - i):
        if zahlen[j] > zahlen[j + 1]:
            zwischenspeicher = zahlen[j]
            zahlen[j] = zahlen[j + 1]
            zahlen[j + 1] = zwischenspeicher
            tausche = tausche + 1

print("Sortiert:", zahlen)
print("Anzahl Täusche:", tausche)

Aufgabe 6:

Protokoll nach jedem Durchlauf

Beim Lernen von Bubble Sort hilft ein Protokoll: Nach jedem äußeren Durchlauf sieht man, wie sich das Array verändert – besonders, dass die größten Werte nach rechts „wandern“.

Gegeben ist das Array zahlen = [4, 1, 3, 2]. Erweitert den Bubble Sort so, dass nach jedem äußeren Durchlauf der aktuelle Zustand des Arrays ausgegeben wird.

Erwartete Ausgabe

Nach Durchlauf 1: [1, 3, 2, 4]
Nach Durchlauf 2: [1, 2, 3, 4]
Nach Durchlauf 3: [1, 2, 3, 4]
▼ Lösung anzeigen
zahlen = [4, 1, 3, 2]
laenge = len(zahlen)

for i in range(1, laenge):
    for j in range(0, laenge - i):
        if zahlen[j] > zahlen[j + 1]:
            zwischenspeicher = zahlen[j]
            zahlen[j] = zahlen[j + 1]
            zahlen[j + 1] = zwischenspeicher
    print("Nach Durchlauf", i, ":", zahlen)

Aufgabe 7:

Highscore-Liste absteigend sortieren

Für ein Computerspiel soll eine Highscore-Liste angezeigt werden. Die höchsten Punktzahlen sollen oben stehen, also absteigend sortiert sein.

Gegeben ist das Array scores = [12, 5, 9, 3, 15, 7]. Passt den Bubble Sort so an, dass die Werte absteigend sortiert werden. Es ändert sich nur die Vergleichsbedingung.

Erwartete Ausgabe

[15, 12, 9, 7, 5, 3]
▼ Lösung anzeigen
scores = [12, 5, 9, 3, 15, 7]
laenge = len(scores)

for i in range(1, laenge):
    for j in range(0, laenge - i):
        if scores[j] < scores[j + 1]:
            zwischenspeicher = scores[j]
            scores[j] = scores[j + 1]
            scores[j + 1] = zwischenspeicher

print(scores)

Aufgabe 8:

Nach wie vielen Durchläufen ist das Array sortiert?

Die äußere Schleife von Bubble Sort läuft oft weiter, obwohl das Array bereits sortiert ist. Für das Verständnis ist wichtig zu wissen: Nach dem wievielten Durchlauf war das Array erstmals sortiert?

Gegeben ist das Array zahlen = [8, 3, 5, 1, 2]. Schreibt ein Programm, das Bubble Sort ausführt und nach jedem Durchlauf prüft, ob das Array bereits aufsteigend sortiert ist. Speichert in einer Variablen, beim wievielten Durchlauf das Array erstmals sortiert war. Am Ende gebt ihr diese Anzahl und das sortierte Array aus.

Tipp: Nach einem Durchlauf prüft ihr mit einer Schleife, ob jedes Element kleiner oder gleich dem nächsten ist. Merkt euch den ersten Durchlauf, bei dem das zutrifft (z. B. nur speichern, wenn die Variable noch 0 ist). Verwendet kein break.

Erwartete Ausgabe

Fertig nach 3 Durchläufen: [1, 2, 3, 5, 8]
▼ Lösung anzeigen
zahlen = [8, 3, 5, 1, 2]
laenge = len(zahlen)
fertig_nach = 0

for i in range(1, laenge):
    for j in range(0, laenge - i):
        if zahlen[j] > zahlen[j + 1]:
            zwischenspeicher = zahlen[j]
            zahlen[j] = zahlen[j + 1]
            zahlen[j + 1] = zwischenspeicher

    # Prüfen, ob bereits sortiert
    schon_sortiert = True
    for k in range(laenge - 1):
        if zahlen[k] > zahlen[k + 1]:
            schon_sortiert = False

    if schon_sortiert:
        if fertig_nach == 0:
            fertig_nach = i

print("Fertig nach", fertig_nach, "Durchläufen:", zahlen)
